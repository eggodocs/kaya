#   Negate

Provides the negation of a number value.


Type ID: `kaya:negate`


!!! note
    
    This number meta type can only provide the same kind of value of the field where it was used. *(e.g: if the field is a float provider, the number provider to specify should be a float provider or if the field is an int provider, the number provider to specify should be an int provider)*


### Format

Field | Type | Default | Description
------|------|:-------:|------------
`value` | Number Provider | | The number to get its negation from.


### Example

```json
{
    "type": "kaya:negate",
    "value": 100
}
```

This example is an int provider that will provide the negation of $100$ (which will be $-100$ since the negation of a positive number is negative.)
