#   Difficulty

Checks the difficulty of the world.


Type ID: `neo-apoli:difficulty`


### Format

Field | Type | Default | Description
------|------|:-------:|------------
`difficulty` | [Difficulty]({{ mc.difficulty }}) | | The difficulty to match.


### Example

```json
{
    "type": "neo-apoli:difficulty",
    "difficulty": "normal"
}
```

This example checks if the current difficulty is set to normal.
