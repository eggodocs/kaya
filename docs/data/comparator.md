#   Comparator

A [string][string] that indicates how a two comparable objects should be compared.


### Values

Value | Description
------|------------
`==` | Checks if the first object is equal to the second object.
`!=` | Checks if the first object is **not** equal to the second object.
`>` | Checks if the first object is greater than the second object.
`>=` | Checks if the first object is greater or equal than the second object.
`<` | Checks if the first object is less than the second object.
`<=` | Checks if the first object is less than or equal to the second object.
