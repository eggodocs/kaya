#   Object

Objects are enclosed in curly braces and contain key-value pairs separated by commas.


### Example

```json
{
    "field": "Hello world!",
    "numbers": [
        67,
        520
    ]
}
```

This example provides an object with key-value pairs of `field` *(which has a [string][string] value of `"Hello world!"`)* and `things` *(which has an [array][array] of [integers][integer] whose values are `[67, 520]`)*
