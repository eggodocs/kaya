#   Kaya's Documentation

This repository is used for managing Kaya's documentation site.


##  Contributing

1. Fork this repository, and clone the fork locally with `git clone https://github.com/<your_username>/kaya`.
2. Install Python, reboot, and install the prerequisites in `requirements.txt` with `pip install -r requirements.txt`. This will install everything needed by the site.
3. Make your changes and preview them via `properdocs serve`.
