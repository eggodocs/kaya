#   Getting started


## Pre-requisites

Before getting started with creating things with Kaya, there are some things that you must know first as Kaya has a flexible but fairly complex design philosophy:

* Creating things with Kaya will involve creating/using resource/data packs and a lot of JSON files, so be sure to familiarize yourself with JSON formats and with how to create resource/data packs and how it works.
* Most if not all types in Kaya are **contextual**, which means that you'll have to remember which parameters are provided in which scope[^1]. Make sure to check the pages for types you desire to use to ensure you don't miss a detail.


## Relevant links

[^1]: [Powers][power], and sometimes, [actions][action], [conditions][condition], or even [value providers][value_provider], will provide the parameters for other types to function, but parameters can also be manually provided when needed.
