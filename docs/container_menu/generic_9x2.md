#   Generic 9x2

Provides a container that has 2 rows and 9 columns.


Type ID: `neo-apoli:generic_9x2`


### Format

*No additional fields.*


!!! tip

    This container menu type can be inlined by providing a string that matches the type ID.


### Example

=== "Full"

    ```json
    {
        "type": "neo-apoli:generic_9x2"
    }
    ```

=== "Inlined"

    ```json
    "neo-apoli:generic_9x2"
    ```
