#   Particle Effect

A [string][string] or an object that defines a particle.


### Format

Field | Type | Default | Description
------|------|:-------:|------------
`type` | [Identifier]({{ mc.particle_type_identifier }}) | | The ID of the desired particle type.


???+ info

    See [Minecraft Wiki: Particle format](https://minecraft.wiki/w/Particle_format) for more information about the additional fields for each particle type.
